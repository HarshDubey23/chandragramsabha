   180→   - **IP allowlist** (`VAPI_IP_ALLOWLIST`): if set, only IPs in the comma-separated list are allowed (403 otherwise); if unset, all IPs allowed with a console warning.
   181→   - **HMAC-SHA256 verify** (`x-vapi-signature` header vs `HMAC-SHA256(rawBody, VAPI_SECRET)`): constant-time compare via `crypto.timingSafeEqual`. Skipped in dev mode (secret unset OR `= dev-secret`) with warning.
   182→   - **Idempotency** — `db.complaint.findFirst({ where: { vapiCallId } })` → returns `{ ok: true, deduped: true }` if a row already exists.
   183→   - **Insert** — tracking id `GPCH-${Date.now().toString(36).toUpperCase()}`, parses `message.call.{id, customer.number, transcript, analysis.structuredData.{caller_name, call_reason, category}}`, defaults category to `other`, sets status `Pending`, builds initial timeline entry `{status:'Pending', ts, note:'AI voice assistant filed complaint', by:'vapi-assistant'}`.
   184→   - **Mock WhatsApp dispatch** — formats the Hindi message per §5.4 and writes it both to console AND appends to `whatsapp-outbox.log` (with ISO timestamp + `---` separator).
   185→   - **Return** `{ ok: true, tracking_id }`.
